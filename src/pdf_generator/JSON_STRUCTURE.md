# Report JSON structure

The JSON contains the report's text and metadata. The HTML and CSS control its
presentation. Section and topic titles can change for different types of news.

This document follows the notebook sketch, using the field names in
`sample.json`. It also includes `summary`, which appears in the sample but is
not shown in the sketch.

## Overview

| Field | Type | Purpose |
| --- | --- | --- |
| `language` | String | Report language, such as `en` or `pt-BR`. |
| `category` | String | News category or subject. |
| `title` | String | Main report title. |
| `introduction` | Array of strings | Opening paragraphs, in reading order. |
| `publication` | String | Publication name used throughout the report. |
| `metadata` | Object | Reporting period, generation timestamp, and LLM model. |
| `summary` | Object | Executive summary, stored in `summary.paragraphs` as an array of strings. |
| `sections` | Array of objects | Main report sections, in display order. |
| `sources` | Object | Source list heading and article references. |
| `footer` | Object | Closing paragraphs. |

## AI-generated content

The AI fills the fields that require news synthesis and analysis:

| Field | AI-generated content |
| --- | --- |
| `title` | Report headline reflecting the main developments. |
| `introduction[]` | Introductory paragraphs about the report's content. |
| `summary.paragraphs[]` | Executive summary. |
| `sections[].title` | Section heading, unless predefined by the application. |
| `sections[].topics[].title` | Optional topic heading. |
| `sections[].topics[].paragraphs[]` | News synthesis, context, and analysis. |
| `sections[].topics[].bullets[]` | Optional key points. |

The application supplies the remaining fields from configuration, scraped
articles, or automatically calculated values:

- `language`, `category`, and `publication`: report configuration.
- `metadata.period`: reporting dates from the selected articles or requested period.
- `metadata.generatedAt`: report generation timestamp.
- `metadata.model`: the configured LLM model.
- `sources.title`: a predefined heading.
- `sources.items[]`: article titles, outlets, publication timestamps, and URLs from the source data.
- `footer.paragraphs[]`: predefined editorial notes.

The application combines the AI-generated content with these fields to produce
the complete report JSON. Source references and metadata do not need to be
generated by the AI.

## Metadata

- `period.start` and `period.end`: dates covered by the report, in `YYYY-MM-DD` format.
- `generatedAt`: generation timestamp in ISO 8601 format, including a time zone, such as `2026-09-14T09:00:00-03:00`.
- `model`: name of the LLM used to generate the report.

## Sections and topics

Each section has a `title` and a `topics` array of objects, even when there is
only one topic. Each topic contains:

- `title`: optional topic heading. Omit it when no subheading is needed.
- `paragraphs`: array of strings, with one paragraph per entry.
- `bullets`: optional array of strings, with one short list item per entry.

Render topics in array order. Within each topic, render its title, paragraphs,
then bullets. Empty arrays produce no content.

```json
{
  "title": "Key developments",
  "topics": [
    {
      "title": "Brazil",
      "paragraphs": [
        "First paragraph about Brazil.",
        "Additional context."
      ],
      "bullets": [
        "A key point.",
        "Another key point."
      ]
    },
    {
      "title": "International",
      "paragraphs": ["International developments."]
    }
  ]
}
```

A section without subheadings uses one topic without a `title`:

```json
{
  "title": "Macroeconomic analysis",
  "topics": [
    {
      "paragraphs": ["Analysis paragraph."]
    }
  ]
}
```

## Sources

`sources.title` is the heading for the references section. `sources.items` is
an array of article references, each containing:

| Field | Type | Purpose |
| --- | --- | --- |
| `title` | String | Article title. |
| `outlet` | String | Publisher or news outlet. |
| `publishedAt` | String | Publication timestamp in ISO 8601 format, including a time zone. |
| `url` | String | Link to the original article. |

## Footer

- `paragraphs`: array of closing notes, with one paragraph per entry.

## Rendering conventions

- Keep paragraph and bullet content as plain text, without HTML or Markdown.
- Preserve array order when displaying sections, topics, paragraphs, bullets, and sources.
- Treat missing `bullets` as an empty array and missing topic titles as no subheading.
- Format dates for display in JavaScript; keep the stored date values consistent.
- The JSON contains no HTML IDs. The renderer assigns IDs when creating elements; titles are display text, not identifiers.
